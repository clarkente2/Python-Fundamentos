# Python — Fundamentos

Repositório criado durante meus estudos de **Python 3**, com exercícios e pequenos projetos desenvolvidos para praticar lógica de programação e fundamentos da linguagem.

O objetivo é registrar minha evolução prática enquanto desenvolvo uma base sólida para aplicações e projetos de software.

## 📚 Conteúdos praticados

* Variáveis e tipos de dados
* Entrada e saída de dados
* Estruturas condicionais
* Estruturas de repetição
* Funções
* Listas e dicionários
* Manipulação de strings
* Operadores e expressões
* Validação de dados
* Modularização
* Tratamento básico de problemas e regras de negócio

## 🛠️ Projetos e exercícios

### 🔐 Gerador e Validador de CPF

Implementação de algoritmos para geração e validação de números de CPF, utilizando regras matemáticas para cálculo dos dígitos verificadores.

### 🧮 Calculadora Interativa

Aplicação executada pelo terminal para realização de operações matemáticas a partir das entradas fornecidas pelo usuário.

### ❓ Quiz

Pequeno programa interativo desenvolvido para praticar estruturas condicionais, entrada de dados e controle de fluxo.

### 🔤 Jogo da Palavra Secreta

Jogo executado no terminal no qual o usuário tenta descobrir uma palavra utilizando tentativas e manipulação de strings.

### 🔢 Outros exercícios

O repositório também contém exercícios menores desenvolvidos durante o processo de aprendizagem, explorando diferentes conceitos da linguagem Python.

## 🎯 Objetivo do repositório

Este projeto faz parte do meu processo de formação em **Análise e Desenvolvimento de Sistemas**.

Além de praticar a sintaxe da linguagem, busco desenvolver capacidade de:

* decompor problemas em etapas;
* criar algoritmos;
* transformar regras em código;
* organizar soluções em funções e módulos;
* escrever código de forma mais clara e reutilizável.

## 🚀 Próximos passos

À medida que avanço nos estudos, pretendo evoluir este repositório e desenvolver projetos mais completos envolvendo:
